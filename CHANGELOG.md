# Changelog

## 1.0.0

- Promote Ambitions Invaders to 1.0.0 in the mod manifest, MCG catalog and assembly metadata.
- Add a dedicated promotional icon in the Flappy Ambitions / Snacke visual style.
- Prepare English and French release descriptions and update notes.
- Build against the separate MCG 1.0.0+ library, with explicit dependency/version checks and private build artifacts kept outside the package.
- Preserve horizontal banknote combat, solid yellow lasers, four rival types, boss waves, all 22 languages and local record identifiers.

## 0.1.0

- Initial MCG game: two-dimensional movement, progressive waves, shields, enemy fire and boss encounters.
- Pixel-art versions of four Big Ambitions rivals and English Unity preview screenshots.
- Local high-score integration through MCG and translations for all 22 game languages.
- Standalone source publication and the `MCG_AmbitionsInvaders` package folder.
